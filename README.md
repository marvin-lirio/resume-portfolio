# Marvin Lirio — Portfolio

Personal portfolio and interactive resume built to showcase my professional background in software quality, technical compliance and product certification while documenting my transition into software development.

**Live Site:**  
https://marvin-lirio.github.io/resume-portfolio/

---

## About the Project

This project began as a static HTML resume and is evolving into a responsive, interactive frontend application built with HTML, CSS and JavaScript.

Rather than simply presenting development skills, the project is intended to demonstrate the development process itself — defining requirements, implementing functionality, validating behavior, iterating on the design and deploying a working product.

My background is primarily in software quality engineering, testing, certification and technical compliance. That experience influences how I approach development: understand the system, identify requirements, build intentionally, test the behavior and improve what doesn't work.

## Development Approach

AI is incorporated into the development workflow as an implementation and problem-solving tool, while I remain responsible for the requirements, direction, review, testing and final behavior of the application.

The general workflow for this project is:

1. **Define** — establish the requirement, problem or desired behavior.
2. **Direct** — use AI-assisted development to accelerate implementation and explore solutions.
3. **Understand** — review the resulting HTML, CSS and JavaScript to understand how the implementation works.
4. **Validate** — test functionality, responsive behavior, interactions and edge cases.
5. **Iterate** — identify issues and refine the implementation.
6. **Ship** — version changes with Git and deploy through GitHub Pages.

This process reflects the quality-focused mindset developed throughout my professional career.
